📚 Endpoints de la API REST Móvil (`/api/mobile/*`)

POST /api/mobile/login

Autenticación segura del socio para obtener el Token JWT de sesión móvil (validez 30 días).

POST /api/mobile/login Content-Type: application/json { "numSocio": "35-178849", "pin": "1234" }
GET /api/mobile/resumen

Obtiene el resumen consolidado de saldos, cartera e información del próximo vencimiento.

GET /api/mobile/resumen Authorization: Bearer {TOKEN_SOCIO}
GET /api/mobile/cuentas

Retorna la lista de cuentas del socio con su número de **CLABE SPEI de 18 dígitos** asignado para depósitos automáticos.

GET /api/mobile/cuentas Authorization: Bearer {TOKEN_SOCIO}
GET /api/mobile/creditos

Obtiene el estado de los créditos vigentes, saldo de capital adeudado y fechas de pago.

GET /api/mobile/creditos Authorization: Bearer {TOKEN_SOCIO}
